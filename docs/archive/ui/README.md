# docz-site archive

Inside this directory an ID means **docz-site's**: `IMPL-0001` here is
docz-site's IMPL-0001, not docz's, and a link between these documents resolves
inside `docs/archive/ui/`. These are docz-site's planning records — its ADRs,
designs, implementation plans, investigations, guides, and changelog — archived
on 2026-09-24 when docz-site moved into this repository as `ui/` (ADR-0004,
DESIGN-0017, IMPL-0020), from
[github.com/donaldgifford/docz-site](https://github.com/donaldgifford/docz-site)
at commit `f1203c9` with their history intact. They are records, not live
documents: nothing here is renumbered or rewritten, and neither the wiki nor the
`api:` listing publishes them. Seven of them are also snapshotted as test data
under `ui/src/mocks/content/`, which is where the UI reads them from; these
copies are the record.
